MINI·SIEM

A security monitoring platform you can run for free. Collect logs from Linux, Windows and web servers, catch attacks in real time, hunt threats with KQL, and watch every incident unfold on a live world map.

Features

Everything below is built and runs in the console.

Log collectionAgent for Linux and Windows, UDP syslog, disk buffering so nothing is lost when the server is down.
Detection engineHot-reloaded YAML rules: brute force, spraying, port scans, web attacks, privilege escalation, off-hours logins.
KQL threat huntingQuery logs with a Kusto-style language, save hunts, bookmark evidence, promote a query to a scheduled detection.
Incidents and timelinesScan, brute force, login and new account merge into one incident that escalates automatically.
Investigation graphPivot from an IP to users, hosts, alerts and incidents in one click.
Live attack mapAttacker locations appear the moment an alert fires, with risk scores that decay over time.
Threat intelligenceFree blocklists imported automatically; matches raise severity and trigger alerts.
Watchlists and automationVIP users, trusted IPs and critical hosts drive rules and auto-triage of new alerts.
Active responsePlaybooks block attackers on the hosts, notify by Telegram or email, and unblock on a timer.
Behaviour analyticsPer-user login baselines and an Isolation Forest flag logins that look unlike the user.
Tamper-evident storageSHA-256 hash chain over every event, plus roles and a full audit log.
ReportsPDF summaries and CSV exports for the review or the SOC shift handover.
